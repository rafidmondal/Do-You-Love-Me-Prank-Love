About Advance Options

Advance Options is a set of free, no-signup mini-tools built on top of the "Do You Love Me?" prank site. Everything runs entirely in the browser — there is no backend server, no account system, and no database. All data (names, questions, answers, and unlock dates) is encoded directly into the link's URL using base64, so the link itself is the only place the data exists.

100% Data Safe — Guaranteed

We do not collect, store, log, or transmit any personal data to any server. Nothing you type is saved anywhere except inside the shareable link you generate. If you lose the link, the data is gone — because there is nothing stored elsewhere to recover it from. This is a privacy-by-design architecture: no server-side storage means no data breach risk from this app.

Frequently Asked Questions

What is Custom Love Prank?

A simple tool where you can optionally add your name and write your own custom question. It generates a shareable link that opens a Yes/No prank page, where the "No" button playfully moves away from the tap, and tapping "Yes" shows a result page confirming the answer.

What is Two-Way Love Decoder?

A compatibility quiz for two people. The first person answers 6 fixed questions. A link is generated and sent to a second person. The second person answers the same 6 questions without ever seeing the first person's answers. Only after both people have answered does a compatibility match percentage get calculated and revealed. The full question-by-question breakdown is visible only to the two original participants; anyone else who opens a shared result link sees a limited preview (2 questions plus the overall match percentage) instead of the full breakdown.

What is Time Capsule Confession?

A tool for writing a message today that stays locked until a future date and time you choose (presets: 1 day, 1 week, 1 month, or a custom date). Anyone who opens the link before the unlock time sees a live countdown timer. After the unlock time passes, the message is revealed automatically with a confetti animation.

What is Sync Pulse?

A two-person, same-device mini-game. Two players share one phone, each tapping their own half of the screen. After a 3-2-Start countdown, both players must tap at the same moment within a 5-second window. The app measures the time difference between the two taps in milliseconds and converts it into a synchronization percentage. The game runs for 2 rounds and averages the results into a final sync score.

Is any data sent to a server or stored in a database?

No. There is no backend, no database, and no analytics collection of the content you enter. Every feature works by encoding the data into the URL hash (the part after the # symbol), which browsers do not send to servers during normal page loads. The link itself is the only "storage" — copying, saving, or sharing the link is the only way the data persists.

Do I need to create an account?

No account, login, or signup is required for any feature on this site.

Is this site installable as an app?

Yes. This site is a Progressive Web App (PWA) and can be installed to a phone's home screen or a desktop for an app-like experience, including offline access to previously visited pages.
